选择操场，绘制路线

自定义路线

  1. 选择附近校区作为地图中心，或者输入 WGS84 经纬度。
  2. 点击“开始绘制”，按移动顺序点击地图。拖动地图可以移动视野。
  3. 环形路线点击“闭合路线”；开放路线会沿原路往返。
  4. 下载 GeoJSON 文件，在操作窗口选择 7 → I 并粘贴文件路径。
