选择操场，绘制路线

自定义路线

  1. 选择附近校区作为地图中心，或者输入 WGS84 经纬度。
  2. 选择“四点足球场”，点击足球场四个角，自动生成跑道；拖动角点可以调整。
  3. 也可以选择“逐点绘制”。环形路线需闭合，开放路线沿原路往返。
  4. 完成绘制后默认保存为新路线，返回操作窗口选择 7 → 对应编号。
